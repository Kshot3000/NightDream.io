# NightDream.io

TapTools-inspired Cardano analytics UI (demo).

**Live:** https://kshot3000.github.io/NightDream.io/

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080/

## Notes

- Static site for GitHub Pages (`main` / root).
- Market figures are **demo data** only — not live feeds.
- Relative asset paths work under `/NightDream.io/`.
