Feed settings

How the board is priced — Minswap's DEX pools first, which prices any Cardano asset ID, then CoinGecko for 24h stats and 7d charts, with an optional Charli3 key as a rescue. The ADA stat is cross-checked against the independent, signed DIA oracle (keyless, browser-safe). The other big Cardano feeds (Sundaeswap, CoinMarketCap, TradingView, OKX, Pyth) were evaluated; each is blocked for a browser-only site — no CORS, majors-only, or retired — so the pipeline above carries the board.

Optional: a free CoinGecko API key (from coingecko.com/api) raises rate limits and unlocks the full Cardano coin list for discovery. Stored only in this browser — never sent anywhere except CoinGecko.

Optional: a Charli3 API key (from charli3.io) adds a third, multi-DEX price source covering 17,000+ tokens — used only as a rescue when Minswap and CoinGecko can't price a token. Stored only in this browser — never sent anywhere except Charli3.

Legacy · taptools.io

From TapTools to NightDream

What the old community dashboard was, what survived of it, and how NightDream picks up the work.

What TapTools was

TapTools (taptools.io) was the Cardano community's go-to token dashboard: a live leaderboard of community tokens (CNTs) ranked by 24-hour volume, top movers, recently added and recently boosted tokens, per-token price charts, NFT boards, Cardano network stats and epoch data — plus a Pro tier with hot-wallet tracking.

In 2026 the site shut down. The domain now serves a farewell page (“Thank You for Being Part of Our Journey”), and every data endpoint it used to expose answers HTTP 404 (verified August 2026). The numbers themselves are gone with the backend.

The old data feed, documented

Honest note: the archived API responses in the Wayback Machine are stored encrypted, and Common Crawl captured only the HTML shells — so the historical numbers cannot be recovered from public archives. If you hold an export of the old data (CSV, JSON, spreadsheets), send it over and it will be folded into this archive.

The story

Built to keep the lights on

Cardano lost some of the tools the community leaned on — token dashboards that went dark with a single decision. NightDream.io is the answer: an open, no-ads dashboard that anyone can read, mirror and rebuild.

Daylight data comes from a small constellation of public sources: Minswap's aggregator for live pool prices, the Cardano Token Registry for official, signature-checked names, CoinGecko for 24h stats and 7d charts, and an optional Charli3 key for wider coverage — all joined to a bundled registry of Cardano Native Tokens. Midnight's night-side data will plug in here as the chain's public indexes mature. Everything runs in your browser — nothing is stored on a server, and nothing is sold.

If you have a backup of old tool data — CSV, JSON, spreadsheets, exports — you'd like preserved, send it over and it will be folded into the heritage archive above.
